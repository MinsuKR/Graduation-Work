# src/atmega/main.cpp 현재 코드 요약

작성 기준 파일: src/atmega/main.cpp
저장 위치: Individual code/실험코드/atmega_main_현재코드_요약.txt

## 전체 목적

현재 활성화되어 있는 코드는 ATmega128 보드에서 Ethernet3 라이브러리와 W5500 계열 이더넷 모듈을 사용해 TCP 서버에 접속하는 통신 실험 코드이다. 16x2 I2C LCD에는 부팅 상태, TCP 연결 상태, HELLO 전송 상태, 서버 응답 결과를 단계별로 표시한다.

파일 앞부분에는 기존 듀얼 로드셀, HX711, 버튼, EEPROM, AutoZero, UART ACK 관련 코드가 주석 처리된 상태로 남아 있다. 실제로 컴파일되어 동작하는 코드는 파일 하단의 Ethernet TCP 테스트 코드이다.

## 사용 라이브러리

- Arduino.h: Arduino 기본 함수 사용
- SPI.h: W5500 이더넷 모듈과 SPI 통신
- Ethernet3.h: Ethernet TCP 클라이언트 기능 사용
- Wire.h: I2C 통신
- LiquidCrystal_I2C.h: I2C LCD 제어

## 주요 전역 설정

- LCD 주소: 0x3F
- LCD 크기: 16열 2행
- Ethernet CS 핀: SS
- MAC 주소: 02:11:22:33:44:58
- 장치 IP: 192.168.0.120
- 서브넷: 255.255.255.0
- 게이트웨이: 192.168.0.1
- DNS: 8.8.8.8
- 접속 대상 서버 IP: 192.168.0.100
- 접속 대상 서버 포트: 5000

## 주요 함수

### lcdShowSafe(line1, line2)

LCD에 두 줄 문자열을 안전하게 출력하는 함수이다. 각 줄을 16자 폭에 맞춰 자르거나 공백으로 채운 뒤 LCD를 지우고 1행, 2행에 출력한다.

### stopHere(line1, line2)

오류가 발생했을 때 LCD에 메시지를 출력한 뒤 무한 루프에 들어가 프로그램을 멈춘다. 예를 들어 LAN 케이블 연결 실패나 TCP 연결 실패 시 사용된다.

### setup()

보드가 시작될 때 한 번 실행되는 핵심 초기화 및 통신 절차이다.

1. LCD를 초기화하고 백라이트를 켠다.
2. Serial 통신을 115200bps로 시작한다.
3. LCD에 Booting 메시지를 표시한다.
4. SPI 핀을 설정하고 SPI를 시작한다.
5. Ethernet CS 핀을 설정한다.
6. 고정 IP 설정으로 Ethernet을 시작한다.
7. Ethernet 링크 상태를 확인한다.
8. 링크가 없으면 LCD에 LINK FAIL / Check cable을 출력하고 정지한다.
9. TCP 서버 192.168.0.100:5000에 접속을 시도한다.
10. 접속 실패 시 TCP FAIL / connect rc<=0을 출력하고 정지한다.
11. 접속 성공 시 TCP Connected를 표시한다.
12. 서버로 HELLO 문자열을 전송한다.
13. 최대 8초 동안 서버 응답을 기다린다.
14. 응답이 없으면 NO REPLY를 표시한다.
15. 응답에 ACK가 포함되어 있으면 ACK OK와 수신 데이터를 표시한다.
16. ACK가 아닌 다른 데이터가 오면 RX DATA와 수신 데이터를 표시한다.
17. 처리가 끝나면 TCP 연결을 닫는다.

### loop()

현재 loop 함수는 비어 있다. 따라서 setup에서 TCP 테스트를 한 번 수행한 뒤 반복 동작은 하지 않는다.

## 동작 흐름 요약

1. LCD 초기화
2. SPI 및 Ethernet 초기화
3. LAN 링크 확인
4. 서버 TCP 접속 시도
5. HELLO 전송
6. 서버 응답 수신 대기
7. ACK 여부 판단
8. LCD에 결과 표시
9. TCP 연결 종료

## 현재 코드의 특징

- DHCP가 아니라 고정 IP를 사용한다.
- TCP 클라이언트로 동작한다.
- 서버가 먼저 연결하는 구조가 아니라 ATmega가 서버로 접속한다.
- 응답 수신은 최대 8초 동안 기다린다.
- 개행 문자 '\n'을 만나면 응답 한 줄이 끝난 것으로 판단한다.
- 연결 실패나 링크 실패 시 무한 루프로 멈춰서 LCD에 오류 메시지를 계속 보여준다.
- loop가 비어 있으므로 재접속이나 반복 송신 기능은 아직 없다.

## 주의할 점

- 서버 IP 192.168.0.100과 ATmega IP 192.168.0.120이 같은 네트워크 대역에 있어야 한다.
- 서버는 5000번 포트에서 TCP 연결을 받을 준비가 되어 있어야 한다.
- 서버가 ACK 문자열을 포함한 응답을 보내야 LCD에 ACK OK가 표시된다.
- Ethernet.link()가 실패하면 케이블, W5500 전원, SPI 배선, CS 핀 설정을 확인해야 한다.
- 파일 앞부분의 주석 처리된 로드셀 관련 코드는 현재 실행되지 않는다.
